DocSift v1.0.0
Sentry Hill Software
Find details buried in your documents.

DocSift searches the contents of TXT, DOCX, and ODT files in a folder and its subfolders. It can also search legacy Word DOC files when LibreOffice is installed. If it is not installed, DocSift continues normally and reports that those DOC files could not be searched. Choose a results-per-file limit of 25, 50, 100, 250, or 500; the default is 100.
It lets you review matching text, open the original file or its location, and export selected matches to TXT, DOCX, ODT, or PDF.

DocSift is fully free. There is no licence code, payment screen, account, subscription, cloud service, or telemetry.

Your source documents are read only. DocSift does not alter them.

To use it, run DocSift.exe.
